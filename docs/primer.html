01 / The idea

Editing the model,
not its prompt.

A model’s weights are learned numbers that transform inputs into outputs. Weight-space programming asks whether another model can inspect those numbers and deliberately modify them.

Three ways to change behavior

Prompting

Change the instructions

The weights stay fixed. You provide different context, examples or rules at inference time.

Training

Optimize the weights

A learning procedure updates parameters to reduce a loss over data.

Direct editing

Specify a change

An editor proposes a targeted parameter modification. Its effects still need to be tested.

Why the idea is exciting

If a small, interpretable change could reliably fix a behavior, it might be easier to audit than a broad retraining run. The difficult word is reliably: model internals are distributed, inputs matter, and changing one component can have unrelated consequences.

What this study actually did

  1. Replay an existing edit. Use the public p50c patch from the original project, rather than claim to have discovered a new one.
  2. Audit its geometry. Independently reconstruct the changed tensors and measure the directional transformation.
  3. Compare behavior. Run baseline, exact patch and a shuffled-direction control on the same four synthetic development questions.
  4. Make a blind-to-outcome prediction. Derive an attention-head ranking from weights, freeze it, then measure attention on twenty synthetic sequences.
“Reading weights” is not introspection into this assistant.

These experiments inspect a separate, available model checkpoint using code and analysis. They do not access the hidden weights of the frontier assistant doing the analysis.

The missing bridge

A weight matrix has measurable structure. Calling a direction a “repetition direction” adds a semantic claim. To connect those levels, we need controlled interventions, competing explanations and unseen inputs, not just an appealing visualization or a favorable example.

Here, the mathematical audit is stronger than the behavioral evidence. The separate reading experiment gives a useful failure: a plausible-looking proxy did not predict what the heads actually did.
