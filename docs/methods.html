05 / Evidence & reproduction

Make the claim smaller than the evidence.

The repository preserves synthetic protocols, code, aggregate results and an independent patch audit. This site is the reading guide, not a substitute for those records.

Evidence ladder

  1. Artifact integrity: established. Model and patch hashes were checked, the intended two tensors reconstructed, and an independent standard-library implementation agreed.
  2. Local geometry: established. The realized change is approximately rank one and reverses the selected component at α = 6.
  3. Local behavioral difference: observed. One baseline-relative completion rescue on four development questions, with a shuffled control that changed which question failed to finish.
  4. General benefit or mechanism: not established. No fresh holdout, broad regression suite, multiple seeds or independent discovery of a new edit.
  5. Weights-only prediction: failed here. The frozen head ranking was essentially uncorrelated with the observed ranking.

Public release boundaries

This is a curated release with fresh Git history. It excludes private data, coordination logs, model weights and raw runtime directories. Some protocol prose was edited for publication. Historical protocol hashes refer to the original frozen documents, not the edited public Markdown.

Do not treat the public commit as a timestamped preregistration.

Prediction and result JSON is preserved, but full original freeze evidence and raw run artifacts are not distributed. The release documents those limits instead of claiming complete independent reproducibility.

Reproduce with care

Begin with the repository README and each experiment’s instructions. The scripts need separately acquired model and upstream artifacts; the public release does not include them. Some freezing scripts overwrite their outputs. Preserve the recorded files and work in a new copy for a new experiment.

The public release itself ran no new model experiment. Tests of arithmetic and analysis are different from rerunning generation.

What would strengthen the result?

  • A new, frozen holdout set and multiple generation seeds.
  • A broader regression suite to measure harm outside the target behavior.
  • Controls that distinguish generic perturbation from directional specificity.
  • A prediction made before behavior is observed, with clear failure criteria.
  • An independently discovered edit, evaluated separately from replaying an existing one.
