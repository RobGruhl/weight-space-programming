Can a language model read another model’s weights, understand what they do, and change its behavior directly?

We followed the Sparks of Weight-Space Programming work into a small, local experiment. The useful result is not one big breakthrough. It is three different kinds of evidence, with three different levels of certainty.

The short version

The published patch was reconstructed and audited. It rescued one unfinished answer on four development questions. A separate attempt to predict attention-head behavior from weights failed its frozen ranking test.

Verified arithmetic

What changed?

Two tensors. An approximately rank-one edit. A directional component reversed, not simply removed.

Inspect the geometry → Limited behavioral evidence

Did it help?

Four correct completions with the patch, versus three at baseline. One seed, four reused questions.

Compare all twelve runs → Negative result

Could we read it?

The weight-derived ranking was essentially uncorrelated with measured previous-token attention.

Start with the distinction

Reconstructing an edit shows that the bytes match. Testing an edit shows what it did on particular inputs. Explaining an edit requires evidence that its proposed mechanism, rather than some other effect, caused the change. These are not interchangeable.

This project tests a narrow slice of the thesis on Qwen3.5-0.8B. It does not show that an assistant can generally understand arbitrary weights, independently invent a useful edit, or improve a larger decision model.
